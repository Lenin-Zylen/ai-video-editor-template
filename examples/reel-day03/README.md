# Example: reel-day03 (28 s talking-head reel)

A complete short-form edit to learn from and copy scenes out of. It was made with this editor for a real channel;
the channel's handle is replaced by `yourhandle` and its face, avatar, footage and music are removed.

- `edit.json` — the takes (clip + start/end per script line), caption groups, full-screen windows, publish settings.
  The raw clips are not included, so `tools/cut.py` cannot rebuild this cut; use it as the pattern for yours.
- `compositions/` — the scenes: `hook` (word-by-word title + dot-field ripple), `day` (series number roll),
  `dots` (an agent dot visiting chats), `trycard` (zoom-through section card), `connect` (logos, lines, data packets),
  `prompt` (typed prompt with caret and three-beat chips), `confirm` (cursor click, week fill, success check),
  `result` (full-screen hero slam + notification stack), `cta` (keyword typed into a comment box), `hud`
  (progress bar, step counter, watermark), `captions` (generated by `tools/captions.py`).
- `index.html` — the root: scene timing with 0.35 s overlaps for transitions, punch-ins, the face sliding out for
  full-screen windows, music and 16 sound effects placed on visible actions.
- `cover/index.html` — the reel cover (needs `cover/assets/face.jpg`: a frame of the speaker looking into the lens).
- `assets/logos/channel-avatar.png` and `cover/assets/logos/channel-avatar.png` placeholders — replace with `brand/logo/channel-avatar.png`.
