# Recording checklist

These habits cut the editing time the most.

## Before you record
- Write the script as numbered cuts (Cut 01 Hook, Cut 02 Series, …), for example `script.pdf` with Cut 01–08.
- Mark which cuts should be full-screen graphics (voice only).
- Use the same room, light and framing every time. Phone vertical, face in the upper third.
- Use a clip-on microphone. Speak at the same distance and energy for every line.

## While you record
- Record the cuts in script order.
- Make the **last take** of each line the good one. If you retake, say "take two" first.
- Do not say "okay", "sorry" or "stop" inside a take. Pause, then start the line again.
- Look into the lens. Lines where you look down get replaced or covered.
- Say product names clearly (for example "delegated", not "dedicated").
- Keep one second of silence at the start and the end of each clip.

## After you record
- Copy the clips into `raw-footages/<slug>/` (one folder per video).
- Put the script PDF in the same folder.
- If you already know the best take for a line, write it down: "Cut 07: clip 175448 at 1:22–1:27".
